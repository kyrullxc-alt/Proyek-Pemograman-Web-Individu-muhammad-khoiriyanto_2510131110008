# ETERNAL REALM Website

Website komunitas Roblox ETERNAL REALM dengan desain blue-purple, responsive, dan interaksi JavaScript.

## Halaman
- index.html - Home
- members.html - Members
- events.html - Events
- join.html - Join ERL

## Figma
Folder `figma` berisi 8 screen:
1. Desktop Home
2. Mobile Home
3. Desktop Members
4. Mobile Members
5. Desktop Events
6. Mobile Events
7. Desktop Join ERL
8. Mobile Join ERL

## Fitur
- Semantic HTML5
- Responsive CSS
- Flexbox dan Grid
- Dynamic DOM JavaScript
- Array of Objects
- Search dan filter members
- Event handling
- Form validation
- Activity/event cards
- Logo mudah diganti melalui `LOGO_URL` di `script.js`

## Menjalankan
Buka `index.html` di browser. Untuk Figma, import 8 SVG dari folder `figma`.
