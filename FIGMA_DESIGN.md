1. Desktop Home
2. Mobile Home
3. Desktop Members
4. Mobile Members
5. Desktop Events

8. Mobile Join ERL

## Design System
- Background: #08090D
- Surface: #11131A
- Secondary Surface: #171A23
- Text: #F5F5F7
- Muted: #A8ADBA
- Blue: #4F8CFF
- Purple: #8B5CF6
- Border: #252936
- Font: Arial / sans-serif

## Prototype Flow
Home -> Members
Home -> Events
Home -> Join ERL
Members -> Join ERL
Events -> Join ERL
Join ERL -> Success State

## Import ke Figma
1. Buat Design File baru di Figma.
2. Pilih Import.
3. Masukkan semua 8 file SVG dalam folder figma.
4. Susun Desktop dan Mobile sebagai screen terpisah.
5. Hubungkan tombol/navbar menggunakan Prototype.
6. Bagikan dengan akses Anyone with the link -> Can view.
